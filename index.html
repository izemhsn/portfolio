    Vue 3, TypeScript, WebSockets

xTremio

Stateless, multi-user Stremio add-on

Node.js / Express 5 / Vitest / GitHub Actions

Open source

A stateless, secure streaming add-on for Stremio, built with Node.js and Express 5. One instance serves many users.

  • No database needed. Each user’s credentials live in an encrypted install link.
  • Built for unreliable upstreams. A REST API with paginated search, 30-minute TTL caching, rate limiting, and retries with backoff.
  • 590+ unit tests with Vitest, run automatically in GitHub Actions CI.
