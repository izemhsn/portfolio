Web apps

Vue / Nuxt / TypeScript

  • Admin portal

    A self-service portal for 3POS customers and staff that I built as the main developer, on REST APIs and in four languages. Customers order modules and pay through Stripe, pause or change their subscriptions, download invoices as PDF and manage their own users. Admins and resellers manage companies, products and discounts, and role-based access decides what each of the four account types sees. Forms are validated with VeeValidate and Zod. It significantly sped up customer onboarding.

    Nuxt, TypeScript, Pinia, Nuxt i18n, VeeValidate, Zod, Stripe, REST APIs

  • Kitchen Monitor

    A real-time Vue app that streams live orders over WebSockets from the POS and online channels to kitchen screens across customer venues.

    I led its migration from Vue 2 to Vue 3, which improved rendering performance by 30%.

    Vue 3, TypeScript, Vuetify, WebSockets, REST APIs

  • Pickup Monitor

    A real-time Vue app that streams live orders over WebSockets from the POS and online channels to pickup screens across customer venues.

    Vue, JavaScript, Vuetify, WebSockets, REST APIs

  • 3POS point of sale

    The 3POS point-of-sale app used daily by restaurant and retail staff. One Vue codebase ships to the browser, to Windows, macOS and Linux desktops, and to iOS and Android tablets.

    Since 2021 I’ve made over 1,000 commits to it: at the till (gift cards, tips, discounts, weighing, on-screen keyboards) and across the back office (items and stock, labels and barcodes, invoices, accounting exports, sales analytics with Excel export, and settings for kiosks, TableBee, delivery and reservations). I cut load times with code splitting, lazy loading and caching.

    Vue, JavaScript, Vuetify, Vuex, Bootstrap, IndexedDB, REST APIs

  • Kiosk and TableBee QR ordering

    A self-service kiosk for fast-food restaurants, and TableBee, a QR-code table ordering app. Diners scan the code on their table, browse the menu with allergen filters, pay with Mollie, PayPal or a gift card, and see live when staff approve their order. I built TableBee’s first menu, cart and checkout in 2021, and later added its all-you-can-eat mode, session timeouts, minimum order values and Mollie payments. Both apps boosted order volume, cut counter workload and sped up table turnaround.

    Vue, JavaScript, TypeScript, Vuetify, Vuex, Socket.IO, REST APIs

  • LocalBee online ordering

    LocalBee, an online ordering web app for restaurant delivery and pickup that I worked on from its first version in 2021. Diners browse the menu, check their address against the delivery area, apply coupons, schedule orders and pay online with PayPal or Mollie, then follow their order on a tracking page. Accounts keep addresses, order history and favorite restaurants, in German, English and French. Orders go straight to the restaurant’s POS and Kitchen Monitor. It improved order accuracy for staff and customers.

    Vue, JavaScript, Vuetify, Vuex, Vue I18n, PWA, REST APIs

  • PlaceBee table reservations

    PlaceBee, a table reservation web app for restaurants that I built as the main developer from 2021. Guests choose a reservation type and party size, pick from the times still free, choose tables that fit their group, pre-order dishes and confirm. The receipt carries a QR code and can be saved as a PDF or added to a calendar. Each venue sets its own colors, texts and opening hours and can skip the table or dish steps, in German, English and French. Real-time availability prevents double bookings.

    Vue, JavaScript, Vuetify, Vuex, Vue I18n, REST APIs

  • Product websites

    Launched and maintained seven responsive WordPress marketing and help-center sites for the company’s products, including 3pos.de and localbee.de.

    WordPress, Elementor

xTremio

Stateless, multi-user Stremio add-on

Node.js / Express 5 / Vitest / GitHub Actions

Open source

A stateless, secure streaming add-on for Stremio, built with Node.js and Express 5. One instance serves many users.

  • No database needed. Each user’s credentials live in an encrypted install link.
  • Built for unreliable upstreams. A REST API with paginated search, 30-minute TTL caching, rate limiting, and retries with backoff.
  • 590+ unit tests with Vitest, run automatically in GitHub Actions CI.
